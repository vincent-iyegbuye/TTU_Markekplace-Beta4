**Team:** Beta 4

## Project Overview

TTU Marketplace is a campus-focused web application designed to help Texas Tech University students buy, sell, and discover secondhand items within their university community. Students can browse listings for textbooks, electronics, furniture, clothing, and school supplies, post items they no longer need, and contact other students about potential purchases.

The goal is to make student-to-student exchanges more convenient, organized, and approachable by bringing listings, communication, and campus pickup planning into one place.

| **App Type** | Campus marketplace / buying-and-selling web app |
| **Problem It Solves** | TTU students often rely on general social media, group chats, and word of mouth to buy or sell used items, making listings difficult to find and transactions harder to coordinate. ## Core User Journey

1. Open the **Home** page and choose **Browse Listings**.
2. Search or filter listings to find a relevant item.
3. Select **View Details** to learn more about its price, condition, and seller.
4. Choose **Message Seller** to discuss the item and a possible campus pickup.
5. Alternatively, choose **Add Listing** to post an item for sale.

## Planned Technology

- **HTML5:** Page structure, navigation, forms, and semantic content.
- **CSS3:** Shared layout, typography, cards, buttons, responsive styling, and form focus states.
- **JavaScript (if needed):** Search, filters, favorites, and other front-end interactions in a later development stage.
- **Git and GitHub:** Individual branches, commits, pull requests, and team collaboration.

> **Milestone 1 scope:** The site is a front-end work in progress. Visible controls and page-to-page navigation will be built first; working accounts, persistent listings, and real messaging are not claimed as complete.

## Repository Structure

```text
ttu-marketplace-beta4/
├── index.html
├── css/
│   └── styles.css
├── images/
│   └── (image and icon assets)
└── README.md
```

Every page is a separate HTML file. **All CSS belongs in `css/styles.css`**; no inline `style` attributes or HTML `<style>` blocks will be used. Each team member will place an HTML comment with their name at the top of their assigned page.

## How to View the Website

1. Clone this repository or download its files.
2. Open `index.html` in a web browser.
3. Use the navigation links to visit the other pages.

No special installation is required for the initial static website.
